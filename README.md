# Pillowe's Toolkit

## 介绍
- Pillowe's Toolkit 是一个基于 PyQt5 构建的桌面应用程序。你是否已经受够了在Explorer.exe中一遍遍翻找想要运行的程序、想要访问的目录？是否曾想要更新某个软件或者找某个在线文档，但因忘记官网是什么而红温？不如试试Pillowe's Toolkit，它可以帮你记住软件/程序/文件/目录的位置和相关链接，并在需要时一键运行。
- **目前在Windows 11系统运行正常，其他系统没试过**

## 主要功能
- 存储常用文件，用户可备注标题、网址、路径等，然后一键启动
- 能够设置开机自启，不需要时会安静待在托盘
- 可以自动从gitee获取更新


## 使用说明
- **即食**
